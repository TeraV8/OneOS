FS-2409A FILE SYSTEM DEFINITION
FOR USE ON PARTITIONS NO LARGER THAN 32 MiB (65536 SECTORS)
DEFINITION IDENTIFIER: FS-2409A
COMMON NAME: OneOS Boot FS 32-bit

SECTOR 0: VOLUME INFORMATION
BYTES 000-007: ASCII "FS-2409A"
BYTES 008-01E: ASCII VOLUME LABEL
BYTE      01F: 0x00
BYTES 020-02F: VOLUME UUID
BYTES 030-031: RELATIVE SECTOR LOCATION OF BOOT TEXT
BYTES 032-033: SECTOR SIZE OF BOOT TEXT
BYTES 034-035: RELATIVE SECTOR LOCATION OF BOOT DATA
BYTES 036-037: SECTOR SIZE OF BOOT DATA

BYTES 03C-03F: OS VERSION
